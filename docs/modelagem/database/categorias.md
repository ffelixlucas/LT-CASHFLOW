# Categorias

## Função

Organizar narrativa financeira sem rigidez contábil.

## Tipos sugeridos

- Fixas do sistema (não apagáveis),
- Customizadas pelo usuário,
- Tags opcionais futuras para granularidade transversal.

## Regras

- Mudança de categoria retroativa deve atualizar agregações de forma previsível (batch/async se pesado).
- Ícones/cores estáveis para reconhecimento rápido (`docs/modelagem/ux/padronizacao-visual.md`).
