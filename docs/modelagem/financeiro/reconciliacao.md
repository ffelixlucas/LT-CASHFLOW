# Reconciliacao

## Objetivo

Comparar lançamentos internos com extratos reais.

---

## Entradas possíveis

- OFX
- CSV
- extratos bancários
- APIs futuras

---

## Funções

- detectar duplicidade
- sugerir categorias
- identificar padrões
- validar lançamentos

---

## Filosofia

O sistema deve ajudar o usuário a confiar no extrato.
