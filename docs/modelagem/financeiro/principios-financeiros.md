# Principios Financeiros

## Clareza

O usuário deve entender:
- para onde o dinheiro foi
- de onde veio
- quanto realmente possui disponível

---

## Rastreabilidade

Toda movimentação deve ser auditável.

---

## Simplicidade operacional

O sistema deve simplificar entendimento financeiro.

---

## Confiança

O usuário deve confiar no extrato e no saldo.
