# Automações futuras

## Princípio

Automação reduz trabalho repetitivo sem reduzir **confiança**. Toda automação tem:

- escopo explícito,
- preview,
- reversão ou compensação.

## Ideias priorizadas

1. **Regras de categorização** (“se descrição contém X e conta Y → categoria Z”).
2. **Detecção de assinaturas** a partir de recorrência estatística simples antes de ML pesado.
3. **Emparelhamento de transferências** entre contas.

## Feature flags

Gradual rollout por gestão; logs de decisão armazenados anonimizados para tuning.
