# Analytics de produto

## Princípios

- Eventos nomeados com schema estável (`snake_case`, propriedades mínimas).
- Nunca enviar valores monetários brutos a terceiros sem política explícita.
- Preferir **métricas de outcomes** (conciliação completa, meta atualizada) a vanity metrics.

## Instrumentação sugerida

- Page views em marketing.
- Funil onboarding autenticado.
- Erros de API agregados por código.

## Ferramenta

Escolher provider compatível com privacidade (detalhe operacional em roadmap de dados).
