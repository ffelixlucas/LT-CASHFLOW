# Visao Arquitetural — LTCashFlow

## Foundation principal

O LTCashFlow utiliza:

- monólito modular
- Next.js App Router
- TypeScript
- MySQL
- Drizzle ORM
- TailwindCSS
- Zod

---

## Filosofia arquitetural

Priorizar:

- simplicidade operacional
- domínio financeiro forte
- rastreabilidade
- produtividade
- baixo custo operacional

Evitar:

- microserviços prematuros
- event sourcing desnecessário
- complexidade artificial

---

## Organização do sistema

Estrutura principal:

- apps/web
- packages/db
- packages/validation
- docs

---

## IA operacional

A IA deve:

- auxiliar lançamentos
- interpretar extratos
- acelerar operação
- categorizar movimentações
- gerar insights financeiros

A IA NÃO deve substituir:

- regras financeiras oficiais
- domínio financeiro central

---

## Objetivo futuro

Criar:

- plataforma financeira contextual
- copiloto financeiro operacional
- memória arquitetural viva
- RAG interno do produto
