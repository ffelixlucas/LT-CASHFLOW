# Fluxo do Extrato

## Objetivo

O extrato é a tela principal do LTCashFlow.

---

## Função

Permitir que o usuário:

- entenda movimentações
- acompanhe saldo
- filtre operações
- encontre inconsistências
- navegue rapidamente

---

## Filosofia

Extrato deve parecer:

- rápido
- claro
- operacional
- confiável

---

## Prioridades visuais

- valor
- descrição
- data
- categoria
- conta
- status

---

## Mobile first

O extrato deve funcionar perfeitamente em dispositivos móveis.
