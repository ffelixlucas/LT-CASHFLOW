# Dashboard — Principios

## Objetivo

O dashboard deve resumir rapidamente a situação financeira.

---

## O dashboard NÃO é

- centro do produto
- substituto do extrato

---

## O dashboard É

- resumo
- visão rápida
- orientação
- contexto

---

## Prioridades

- saldo disponível
- entradas
- saídas
- próximos vencimentos
- comportamento financeiro
